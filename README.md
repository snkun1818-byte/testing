# PlanFlow · กองแผนงาน DOAE

เว็บแอปต้นแบบสำหรับจัดการแผน โครงการ งบประมาณ การติดตามผล และพื้นที่ทำงานส่วนตัว อ้างอิงแผนปฏิบัติราชการกรมส่งเสริมการเกษตร ระยะ 5 ปี พ.ศ. 2571–2575

## เปิดใช้งาน

เป็นเว็บ static ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

- เปิด `index.html` โดยตรงในเบราว์เซอร์ หรือ
- รันเว็บเซิร์ฟเวอร์ในโฟลเดอร์นี้ด้วย `python -m http.server 8080` แล้วเปิด `http://localhost:8080`

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository
2. เปิด **Settings → Pages**
3. เลือก **Deploy from a branch**, เลือก branch `main` และ folder `/ (root)` แล้วกด Save
4. เปิด URL ที่ GitHub Pages แสดงให้

ไม่มี dependency ภายนอก จึงนำไป deploy เป็นเว็บไซต์ static ได้โดยตรง

## ฟังก์ชันในต้นแบบ

- เลือกประเด็นการพัฒนา แล้วเปิดดูกลยุทธ์และแนวทางดำเนินงานตามลำดับ
- แสดงเป้าหมายครบทั้ง 36 ข้อ ครอบคลุม 5 ประเด็น พร้อมกลยุทธ์ 26 รายการและแนวทางดำเนินงาน 153 ข้อ
- เปิดเล่มแผนฉบับเต็มจากหน้าเว็บได้
- ภาพรวมแผนและตัวชี้วัดผลลัพธ์หลัก 7 รายการ
- เพิ่ม/แก้ไข/ลบโครงการ เชื่อมกับประเด็นพัฒนาและตัวชี้วัด
- บันทึกผลล่าสุดและความก้าวหน้าของตัวชี้วัด
- ติดตามงาน เช็กลิสต์ส่วนตัว กำหนดส่ง และปฏิทิน
- โน้ตส่วนตัวพร้อมปักหมุดและค้นหา
- ส่งออกตารางเป็น CSV และสำรอง/นำเข้าข้อมูลเป็น JSON
- ปรับหน้าจอสำหรับมือถือ แท็บเล็ต และคอมพิวเตอร์

โครงการตั้งต้นบางรายการมาจากตารางโครงการท้ายเล่มแผน โดยช่องผู้รับผิดชอบ งบประมาณ และสถานะเริ่มต้นยังเว้นไว้เพื่อให้ผู้ใช้ตรวจสอบและกรอกข้อมูลจริง

## ข้อจำกัดของรุ่นนี้

GitHub Pages ให้บริการไฟล์เว็บไซต์แบบ static ข้อมูลที่ผู้ใช้เพิ่มจึงบันทึกใน `localStorage` ของเบราว์เซอร์และอุปกรณ์นั้น ไม่ได้แชร์กับผู้ใช้อื่น และไม่มีระบบล็อกอิน/สิทธิ์แบบหน่วยงาน หากจะใช้เป็นฐานข้อมูลร่วมจริง ต้องต่อ backend และระบบยืนยันตัวตน เช่น API ภายในหน่วยงาน หรือบริการฐานข้อมูลที่หน่วยงานอนุมัติ ก่อนนำข้อมูลราชการจริงเข้าใช้

## โครงสร้างไฟล์

- `index.html` — หน้าจอและโครงสร้างระบบ
- `styles.css` — รูปแบบ responsive สำหรับทุกขนาดจอ
- `app.js` — การทำงานและการจัดเก็บข้อมูลในเบราว์เซอร์
- `plan-data.js` — เนื้อหาเป้าหมาย กลยุทธ์ และแนวทางดำเนินงานที่จัดโครงสร้างตามเล่มแผน
- `assets/doae-plan-2571-2575.pdf` — เล่มแผนฉบับเต็มสำหรับเปิดอ่านจากเว็บไซต์
- `README.md` — วิธีเปิดใช้และ deploy ด้วย GitHub Pages
